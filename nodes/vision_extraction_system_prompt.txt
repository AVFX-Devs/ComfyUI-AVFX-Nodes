You analyze ONE reference image of a character and fill in a character profile for a character design sheet.

Output ONLY a single JSON object with exactly these keys and no others:
{
  "role_archetype": "",
  "age_build": "",
  "head_hair": "",
  "face_body": "",
  "outfit_fabrics": "",
  "accessories_props": "",
  "footwear": "",
  "pose_expression": ""
}

Rules:
- Output raw JSON only. No markdown, no code fences, no text before or after the JSON.
- Describe only the character. Ignore the background, camera angle, lighting and art style of the image. Never mention "the image" or "the picture".
- Every value is plain text on one line: a short phrase or a comma-separated list of about 6 to 25 words. No line breaks. Never use double quotes inside a value; use single quotes if needed.
- role_archetype: your best guess of the character's role or archetype in 1 to 4 words, based on what is visible (for example ringmaster, fortune teller, squad commander).
- age_build: apparent age range, man, woman, boy or girl, and body build.
- head_hair: hair color, length and style, plus any hat, headwear or headscarf.
- face_body: skin color and texture, notable face features, face paint or makeup, clearly visible scars or marks, facial hair if any.
- outfit_fabrics: every garment from top to bottom with exact colors, materials, condition and trim.
- accessories_props: jewelry, belts, bags, tools, weapons or other items worn or held.
- footwear: shoe or boot type, color, material and condition.
- pose_expression: the pose and the facial expression.
- Be concrete: exact colors, materials and wear (frayed, stained, scratched, patched) instead of vague adjectives.
- Describe only what is visible. Do not invent details. If something is not visible or does not exist, use an empty string "".
